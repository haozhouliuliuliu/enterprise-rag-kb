# 架构与数据流

## 架构概览

系统以 AnythingLLM Desktop 为应用层，本机维护文档工作区和检索索引；阿里云百炼用于文本向量化和回答生成；独立评测脚本通过 Developer API 验证检索与回答结果。

                                    |

## 组件职责

| 组件 | 职责 |
| --- | --- |
| AnythingLLM Desktop | 工作区、文档导入、检索流程与引用展示 |
| 本机索引 | 保存解析后的片段与检索索引 |
| 百炼 embedding 模型 | 为片段和问题生成向量 |
| 百炼聊天模型 | 根据问题与检索片段生成回答 |
| tests/eval.py | 调用 Developer API，收集检索来源和回答，并按固定规则判定 |

## 主要数据流

1. 使用者导入虚构文档。
2. 应用解析和切分文档，并建立本机索引。
3. 使用者提交问题，应用执行检索。
4. 问题与检索片段发送到配置的模型服务。
5. 应用展示回答和来源片段。
6. Python 评测脚本通过 Developer API 检查检索来源、引用支持与拒答表现。

## 数据与安全边界

本机索引不代表整个请求链路完全离线。外部模型调用会发送用户问题和检索文本；因此只允许使用已获授权的数据。当前仓库使用虚构资料，且项目只面向单机演示验证。
