# 部署与验证

本项目使用 AnythingLLM Desktop 作为 RAG 应用底座。部署步骤适用于受支持的 Windows 桌面环境；请以软件官方发布说明为准，不依赖仓库内的旧版安装快照或旧方案配置。

## 前置条件

- Windows 桌面环境及可用的 Python 运行环境。
- AnythingLLM Desktop。
- 已获授权的模型服务 API key。
- 仅供演示的虚构 PDF / Word 文档。

## 配置步骤

1. 从 AnythingLLM 官方发布渠道安装桌面应用。
2. 在设置中配置兼容的聊天模型与 embedding 模型，并验证连接。
3. 创建工作区，导入 data/ 目录中的虚构文档。
4. 在设置中启用 Developer API。
5. 在当前终端或本机未跟踪的环境文件中设置评测 API 地址、工作区标识和 API key。
6. 先校验题集，再执行全量评测。

评测命令：

    python tests/eval.py

评测脚本会访问本机应用的 Developer API，并记录检索来源、最终回答及判定结果。真实模型调用会产生服务费用，应在运行前确认服务额度。

## 复现与结果

固定题集位于 tests/questions.full.json；最终指标和判定口径见 tests/results/full-30-summary.md。若自行修改文档、模型或应用版本，应重新运行评测并另行记录结果，不要将不同配置的结果直接混合比较。

## 重要提示

- 不要将 API key 放入脚本、截图、日志、README 或提交记录。
- 不要导入真实企业机密、客户资料、工艺参数或个人信息。
- 应用仅按本机演示方案配置；不要将未加固的服务暴露到公网。
- 如凭据曾出现在聊天、日志、提交记录或截图中，应撤销并重新生成。
