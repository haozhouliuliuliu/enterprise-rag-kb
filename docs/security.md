# 安全与数据边界

## 数据范围

所有样例资料、企业名称、产品型号和业务数值均为虚构。此仓库用于验证文档检索、答案引用和无答案拒答，不用于真实生产决策。

## 模型调用的数据流

应用在本机完成文档管理和检索；生成回答时，用户问题及检索到的文本片段会发送到配置的模型服务。仅在获得数据授权并符合组织规则的情况下，才可在真实业务环境使用外部模型。

## 凭据配置

- 模型服务凭据在应用设置或本机环境变量中配置。
- 不将真实凭据、访问令牌、日志或含凭据的截图提交到版本库。
- 示例环境文件只包含占位值。
- 分享仓库前应检查当前文件与历史提交；删除当前文件中的值并不会自动清除 Git 历史。
- 如果凭据曾出现在不受控的记录或提交中，应撤销旧凭据并重新生成。

## 部署范围

本项目定位为单机演示与验证，不提供企业级认证、多租户权限隔离、集中审计或高可用。不要将未经加固的本机服务暴露到公网。

## 使用边界

如组织要求数据完全留在内网，应使用符合组织要求的本地模型与检索服务，并重新进行安全和质量评估。
