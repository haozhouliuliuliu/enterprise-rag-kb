# 示例资料

data/ 中的文档和业务信息均为虚构，用于测试企业文档的检索、版本识别和引用支持能力。

## 内容

资料覆盖产品说明、物料清单、质量规范、校准、设备操作、包装运输、报告、安全和供应商质量等主题，并包含少量旧版本文件，以测试系统区分现行资料与历史资料的能力。

## 使用边界

- 不代表任何真实公司、产品或技术规范。
- 不可用于真实生产、检验、采购或安全决策。
- 不得以真实企业文件替换样例后直接运行评测，除非已取得数据授权并完成适当的数据保护措施。
- 评测结果只适用于当前固定语料与题集。

资料清单见 catalog.txt；评测题集见 ../tests/questions.full.json。
