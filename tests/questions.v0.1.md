# RAG 测试问题集 v0.1（骨架）

> 状态：**未执行**。资料尚未入库，本文件只定义问题、期望来源和判定口径。

## 1. 使用说明

- `期望来源` 指回答应引用的文件；实际以 RAGFlow 返回的 chunk 引用为准。
- `期望要点` 是人工核对答案是否正确的关键词/数值，不要求逐字一致。
- `类型`：`单文档` / `表格数值` / `边界` / `流程` / `跨文档` / `拒答`。
- 每条问题至少检查一次“引用片段是否真的包含该要点”。

## 3. 结果记录

执行后复制 [`results/template.md`](results/template.md) 为 `results/2026-xx-xx-v0.1.md`，逐条填写：

- 实际回答摘要
- 引用数量与引用文件
- 引用片段是否支持结论（是/否）
- 判定（通过/部分通过/失败）
- 备注（chunk 编号、参数问题）
