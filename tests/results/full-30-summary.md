# RAG 固定题集评测结果

## 数据集

- 文档：22 份虚构企业资料。
- 问题：30 道，其中 25 道可回答、5 道无答案。
- 评测维度：Top-5 检索、最终答案来源支持、无答案拒答。

## 最终指标

| 指标 | 结果 |
| --- | ---: |
| Top-5 检索命中 | 21/25（84%） |
| 最终答案来源支持 | 22/25（88%） |
| 无答案正确拒答 | 5/5（100%） |

## 结果解读

基础文档问答与引用链路可用，但并非每个问题都能检索到最合适的依据。相似型号、版本对比和多文档综合问题仍存在检索缺口；表格内容被切分后也可能损失部分结构关系。

本报告仅代表当前虚构语料、题集、应用和模型配置下的评测结果，不代表生产环境准确率。
