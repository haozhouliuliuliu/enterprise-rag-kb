## 执行流程（第二步/第三步）

1. 资料入库并解析完成；
2. 按 `questions.v0.1.md` 逐条提问；
3. 每条记录：回答、引用文件、引用片段是否支持结论；
4. 汇总通过率，失败项写入 `known-issues.md`；
5. 参数调整（chunk 大小、top-k、rerank）后重新跑一遍并保留历史。

## 通过标准

- 事实性回答 100% 带引用；
- 引用片段与结论相关率 ≥ 90%；
- 关键数值 100% 准确；
- 无答案问题能正确拒答；
- 不出现编造数值或虚构来源。
