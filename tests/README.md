# 测试与评测

本项目使用固定问题集评测 RAG 检索、答案来源与无答案拒答。

## 主要文件

- questions.full.json：30 道固定题（25 道可回答问题、5 道无答案问题）。
- eval.py：通过 AnythingLLM Developer API 运行评测。
- results/full-30-summary.md：最终评测指标与口径说明。
- fixtures/：用于验证文档生命周期和切分结果的虚构样例。

## 运行

先设置本机 Developer API 地址、工作区标识与 API key，再执行：

    python tests/eval.py

## 判定口径

- Top-5：检查相关来源是否出现在检索结果前五项。
- 来源支持：检查最终回答是否有足以支持回答的来源证据。
- 无答案拒答：问题在资料中无答案时，系统应明确表示无法确认，不得编造。
- 文档生命周期：新增、删除或更新文档后，索引和检索结果应相应变化。

评测结果对应指定语料、应用配置和模型版本。更换其中任一项后，应重新评测；不可将一次固定题集结果解释为生产环境的总体准确率。
